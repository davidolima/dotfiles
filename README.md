# Dot Files
Esse repositório de armazenar alguns arquivos de configuração que utilizo em alguns programas, DE's e WM's.
 - Os softwares que independem de DE's e WM's podem ser encontrados na branch `Software`.
 - As configurações relacionadas ao Hyprland e os programas que uso com ele estão na branch `Hyprland`.
 - As configurações que uso com o Gnome estão na branch `Gnome`.
 - As configurações que uso com o i3 e com o KDE Plasma e na integração entre os dois estão na branch `i3-Plasma`.
